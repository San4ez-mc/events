# Джерела подій для афіші

Сайти, з яких ми додаємо події до Кіро. Коли просять «пройтись по джерелах»: пройти розділ «Як пройтись» нижче, для кожного джерела запустити імпорт, перевірити звіт і показати користувачу, що додано і що пропущено.

Усі події публікуються від одного профілю **«Зовнішній організатор»** (`external-organizer@listings.kiro.invalid`). Нових профілів під організаторів не створюємо. Кнопка «Зареєструватись / Купити» веде на сторінку події на сайті-джерелі (з `utm_source=kiro&utm_medium=afisha`). У полі `events.source` лежить id джерела, у `events.sourceRef` ідентифікатор сторінки, тому повторний запуск ніколи не створює дублів.

## Джерела

| id | Сайт | Що це | Як читаємо | Затримка між запитами | Статус |
|---|---|---|---|---|---|
| `ottry` | https://ottry.com | Квитки на клубні вечірки, концерти, фестивалі (Київ, Львів, Полтава та ін.), багато Геловіну й нічних подій | sitemap `https://ottry.com/sitemap.xml` (~50 подій) + серверний HTML сторінки: назва, дата, ціна «від», місце, опис | 0,3 с | **працює** (`ottry.ts`) |
| `concert_ua` | https://concert.ua | Концерти, вистави, стендап по всій Україні (~900 сторінок) | sitemap `https://concert.ua/uk/sitemap/eventpages.xml` + JSON-LD (`MusicEvent` і т. п.): місто, адреса, ціна, фото, початок/кінець | 0,6 с | **працює** (`jsonld.ts`) |
| `kontramarka` | https://kontramarka.ua | Концерти, театр, шоу | sitemap `https://kontramarka.ua/uk/sitemap.xml`, адреси подій закінчуються на `.html`, JSON-LD | **10 с** (так вимагає `robots.txt`) | **працює** з фільтром: пропускаємо постійні атракціони (зоопарк, музеї, океанаріум: розділ у хлібних крихтах `ЗООПАРК` тощо, або дата на кожен день); решта (STAND-UP, концерти, театр) публікується. Перевірено 28.10.2026: `robots.txt` ottry і concert.ua не забороняє сторінки подій; для kontramarka діє `Crawl-delay: 10` (враховано в налаштуваннях), карабас просить 1 с.

Ідеї для наступних джерел (не перевірялись): афіші театрів і клубів із JSON-LD, `sky.tickets`, `tickets.fm`, `eventbrite` (Україна). Додати джерело: опис у `SOURCES` у `apps/api/src/integrations/import/event-import.service.ts`, парсер за зразком `jsonld.ts` або `ottry.ts`, тест у `import-parsers.spec.ts`, рядок у цю таблицю.

## Що парсер пропускає (і пише у звіті)

- Подія, у якої не вказано **місце** (напр. «Буде оголошено», «TBA»), або **ціну** (ottry).
- Місто, якого немає серед 29 активних міст Кіро, або яке не вдалося визначити певно (з назви місця). Невпевнене місто не вгадуємо.
- Скасовані, перенесені й онлайн-події; події в минулому; професійні форуми, конференції, вебінари.
- Подія без обкладинки (картинку завантажуємо безпечно: тільки https, без редиректів, ліміт розміру).
- Якщо на сторінці є дата, але нема часу, ставимо 21:00 і дописуємо в опис «Точний час уточнюйте на сторінці квитків». Час не вигадуємо мовчки.

## Як пройтись (для Claude)

1. На сервері (`root@173.242.62.180`) оновити код, якщо змінювався імпортер: `bash /tmp/deploy-growth.sh` (потрібне явне «так» користувача на деплой).
2. Спершу **пробний запуск** (нічого не пише в базу), подивитись звіт:
   ```bash
   cd /var/www/kiro/apps/api && set -a && . ./.env && set +a
   node scripts/run-import.js ottry '{"dryRun":true,"limit":30}'
   ```
3. Якщо звіт нормальний, той самий запуск без `dryRun`. Звіт містить `created` (що додано), `skipped` (з причинами), `failed`, `nextOffset` (з якого місця продовжити: `{"offset": N}`).
4. Показати користувачу короткий підсумок: скільки додано, які пропущено і чому, де потрібне його рішення (напр. «Ковель: міста нема в Кіро»).

Параметри (усі необов'язкові): `limit` (скільки опублікувати, 25 за замовчуванням), `scan` (скільки сторінок прочитати, 150), `offset`, `from` / `to` (дати ISO; за замовчуванням від зараз), `include` (регулярний вираз по адресі й назві, напр. `"halloween|хелловін"`), `cities` (список наших slug-ів, напр. `["lviv","odesa"]`), `dryRun`.

Приклади:

```bash
# Геловін по Україні, до 2 листопада
node scripts/run-import.js ottry '{"include":"halloween|хелловін|хелоуін|геловін","to":"2026-11-02","limit":40}'
# Найближчі події concert.ua у Львові й Одесі
node scripts/run-import.js concert_ua '{"cities":["lviv","odesa"],"limit":20,"to":"2026-11-30"}'
# kontramarka: повільно, по 8
node scripts/run-import.js kontramarka '{"limit":8,"scan":15}'
```

## Автоматично (cron у FINEKO Flows)

Ті самі запуски можна викликати HTTP-запитом із планувальника Flows, наприклад раз на добу о 06:00 по Києву на кожне джерело:

```
POST https://kiro.fineko.space/api/v1/integrations/import/ottry
Header: X-Bot-Key: <BOT_INTEGRATION_KEY>
Body:   {"limit": 20, "scan": 120}
```

Відповідь — той самий звіт (`created`, `skipped`, `failed`). Ключ той самий, що й для Telegram-інтеграції. Ліміт запитів: 5 на хвилину.

## Прибирання

Події без сторінки-джерела (які ми додавали раніше вручну) теж належать профілю «Зовнішній організатор». Скасувати/сховати подію, яка зникла з джерела, поки вручну: `status = 'CANCELLED'` або відповідна дія в адмінці.
